# Instrucciones del proyecto

- Es un proyecto académico de Actuaría sobre seguros marítimos.
- Mantén el código corto, claro y comprensible para un estudiante.
- Conserva la metodología actuarial y explica cualquier cambio de cálculo.
- No inventes resultados ni sobrescribas datos originales.
- Prioriza reproducibilidad y simplicidad; no añadas herramientas sin valor concreto.
- Cada notebook debe poder ejecutarse de forma independiente.
- Escribe las explicaciones académicas en español.
- Separa observaciones, posibles explicaciones e implicaciones actuariales.
- Verifica cambios importantes con pruebas.
